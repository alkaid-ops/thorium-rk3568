# Thorium on Rockchip RK3568

Tested on Sunniwell Z96A (RK3568B2, Cortex-A55, Mali-G52 r1, eDP 1920×1080,
Devuan 6 / X11).

## Build

```sh
python3 setup.py --raspi          # Thorium's reviewed Linux ARM64 tree
cd chromium/src
cp .../thorium/arm/rk3568/rk3568_args.gn out/thorium/args.gn
python3 build.py --expect-os linux --expect-cpu arm64
```

`rk3568_args.gn` keeps `is_raspi = true` (reviewed ARM64 Linux configuration)
and adds `is_rk3568 = true` for Cortex-A55 code-generation tuning. It does not
change the ARM64 baseline.

### V4L2 hardware decoding

The RK3568 build enables V4L2 instead of VA-API:

```text
use_v4l2_codec = true
use_vaapi = false
use_linux_video_acceleration = true
enable_oop_video_decoder = true
is_rk3568 = true
```

Both stateful (`H264`, `HEVC`, `VP80`, `VP90`) and stateless (`S264`, `S265`,
`VP8F`, `VP9F`) V4L2 paths are compiled in. The out-of-process decoder factory
selects V4L2 and negotiates H.264 `S264` → multi-plane `NV12` on this board.

The hardware-video sandbox must allow the media-controller request API
(`/dev/video*`, `/dev/video-dec*`, `/dev/media-dec*`, `/dev/media0..9`).

Launch wrapper defaults:

```text
--use-gl=egl
--hardware-video-device-path=<resolved /dev/videoN>
```

Resolve the symlink before launching: the sandbox checks the literal path, so
passing `/dev/video-rkvdec` itself fails decoder configuration.

## Verified

| Item | Result |
|---|---|
| H.264 1080p60 | hardware decode, 60.4 fps decoded, 0 steady dropped frames |
| HEVC 1080p60 | hardware decode, 60 fps |
| HEVC 4K | hardware decode; presentation limited by X11/GPU composition (~40 fps) |
| VC-1 / AV1 | no V4L2 request decoder on this SoC |

The 4K presentation limit is a display/composition ceiling, not a decoder
limitation. See the project handoff notes for the 56.5 Hz vsync root cause fix
(VOP PLL rate), which is a kernel/DT change outside this repository.

## Defaults

`initial_preferences.json` in this directory holds the desktop defaults used on
the Z96A image (custom frame, home button, Bing search, memory saver, network
prediction). It is installed as Chromium's `initial_preferences` file.
